# iPhone向け画面設計（案B：LEDドック型）

[English](iphone-layout.md) | **日本語**

iPhoneで使うときの画面構成を定める設計書です。
対象は幅がcompactになるiPhoneの縦向き表示で、iPhone Duoは扱いません。
iPadとmacOSの画面は、現在の構成を維持します。
モックアップは[デザイン案のキャンバス](https://claude.ai/artifact/TVYKLHj5PkKKAhv8iCYpNL)にあります（閲覧には共有設定が必要です）。

## 現状の問題

iOS向けビルドは、macOS向けの画面をそのまま縮めて表示しています。
iPhone 17 Pro（iOS 27シミュレーター）で起動すると、次の問題が起きます。

- Info.plistに起動画面（`UILaunchScreen`）の指定がないため、画面全体がiPhone 4相当の3:2互換表示になり、上下に黒帯が出る。
- 下部パネルが高さ170ptの固定寸法で、LED表示と操作部に幅を半分ずつ割り当てている。再生ボタン列は最小幅が約213ptあり、画面の右端を越えてはみ出す。
- 再生ボタンの高さは34pt、音量の増減ボタンの幅は24ptで、タップ領域の推奨値（44pt）に届かない。
- 歌詞・詳細パネルが一覧の横に最小幅280ptで並ぶため、表示すると一覧が潰れる。ツールバーにもmacOSと同じボタンがすべて並ぶ。

起動画面の問題は、ビルド設定に `INFOPLIST_KEY_UILaunchScreen_Generation = YES` を加えれば解消します。
これは画面設計と独立した修正なので、レイアウトの変更より先に入れます。

## 案Bを選んだ理由

検討した案は3つあります。
案A（iOS標準型）はアートワークを中心にした一般的な音楽アプリの構成で、実装は最も簡単ですが、LED表示はラベル程度に縮小されます。
案C（ポータブル機型）は再生画面を本体に見立てて物理キー風のボタンを並べ、ライブラリを下から引き出すシートに収めます。
案Bは、ライブラリの閲覧をiOS標準のナビゲーションに任せ、LED表示を再生中の表示に集めます。

案Bを採用したのは、このアプリの特徴であるLED表示・状態表示灯・リブ型の音量表示を残しつつ、曲数の多いライブラリや複数編集、プレイリスト管理を標準の操作で扱えるからです。
また、既存のLED表示のビューは高さや角の形を引数で受け取るので、寸法を変えて流用できます。

## 画面構成

### ナビゲーション

最上位は `TabView` とし、「ライブラリ」「プレイリスト」「ビデオ」の3タブと検索タブを置きます。
ライブラリタブは `NavigationStack` で、分類の一覧（すべての曲、アルバム、アーティスト、ジャンル）から各一覧へ進みます。
現在のサイドバー（`NavigationSplitView`）は、iPhoneでは使いません。

### LEDドック（モックアップB-1）

再生項目があるあいだ、タブバーの上にLEDドックを表示します。
iOS 26以降の `tabViewBottomAccessory` を使う想定です。
ドックには曲名（流れる表示）、7セグメントの経過時間、小型のスペクトラム、キー変更中の表示、再生位置の細い線を置き、右端に一時停止／再生と次の曲のボタン（44pt以上）を並べます。
ドックをタップするとデッキを開きます。

### デッキ（モックアップB-2）

デッキは全画面のシート（`fullScreenCover`）で、上から次の要素を並べます。

1. 閉じるボタン、再生中のリスト名、その他メニュー
2. LED表示（幅いっぱい、高さ約300pt）：トラック番号、ファイル形式、曲名、アーティストとアルバム、経過時間、KEY、BPM、曲の構成と再生位置、スペクトラム
3. シークバー（経過時間と残り時間）
4. EQ・KEY・SPEEDの状態表示灯。macOSでは表示専用だが、iPhoneではボタンにし、押すと調整シートを開く
5. 再生操作：停止（小）、前の曲、再生／一時停止（大）、次の曲、出力先
6. 音量：リブ型の表示を横向きにしたスライダー
7. ページ切り替え：「ディスプレイ」「歌詞」「情報」「次に再生」

その他メニューには「調整したコピーを保存」「AACバージョンを作成」「情報を編集…」を置きます。

### 歌詞ページ（モックアップB-3）

歌詞ページでは、LED表示を高さ約90ptの帯に縮め、空いた領域に歌詞を表示します。
時刻付きの歌詞は現在の行を強調し、中央へ自動でスクロールします。
画面下部には縮小した再生操作を残し、右上の「歌詞を編集」から既存の編集画面を開きます。
「情報」ページも同じ配置で、既存の情報表示（アートワークの拡大、情報の編集）を流用します。

### 調整シート

EQ・KEY・SPEEDの表示灯から開くシートで、段階的な高さ（detent）を持たせます。
キーと速度は増減ボタンと現在値、EQはオン／オフ、プリセット、10バンドのスライダーとリバーブを置きます。
macOSのポップオーバー（キー・速度）とEQパネルの中身を、このシートにまとめる形です。

### ビデオ再生

ビデオの再生中は、デッキのLED表示部をビデオに置き換え、全画面表示のボタンを添えます。
ビデオではキーと速度を変更できないので、その表示灯は無効の状態で表示します。

## 機能の配置

現在の機能を、iPhoneのどこから操作するかを次の表に示します。

| 機能 | iPhoneでの配置 |
|---|---|
| 取り込み | ライブラリのその他メニュー「取り込む...」 |
| Finderへの書き出し | その他メニュー。iOSでは現在何もしないため、保存ダイアログか共有シートへの置き換えが必要 |
| 検索・フィルタ | 検索タブ。フィルタは検索画面のナビゲーションバー |
| 並べ替え | 一覧のナビゲーションバーのメニュー |
| 複数編集 | 一覧のその他メニュー「選択」で編集モードに入り、下部ツールバーの「選択項目を編集」で開く |
| 情報を見る、AACバージョンを作成、プレイリストに追加、新規プレイリスト、ライブラリから削除 | 曲の長押しメニュー。削除はスワイプでも行える |
| プレイリスト内の並べ替え・削除 | 編集モードでのドラッグと削除。長押しメニューの「上へ」「下へ」も残す |
| プレイリストの作成・名前変更・削除 | プレイリストタブ |
| プレイリストに曲を追加 | プレイリスト詳細のナビゲーションバーの追加ボタン |
| 再生、一時停止、前の曲、次の曲 | LEDドックとデッキ |
| 停止、シーク、音量 | デッキ |
| キー、速度、EQ、調整したコピーを保存 | デッキの表示灯から開く調整シート。保存はデッキのその他メニューにも置く |
| 楽曲解析（KEY、BPM、曲の構成） | デッキのLED表示 |
| ビジュアライザー | LEDドック（小）とデッキ |
| VUメーター | 縦向きでは表示しない |
| 歌詞の表示・編集 | デッキの歌詞ページ |
| 詳細情報、情報の編集、アートワークの拡大 | デッキの情報ページ |
| 設定 | ライブラリのその他メニューから開くシート |

設定のうち、LEDの配置（パネルレイアウト、LEDの位置、LEDの角）と一覧の列の設定は、iPhoneの画面では使わないので表示しません。
取り込み・書き出しの進捗パネルは、LEDドックに重ならない位置に移します。

## 既存部品の流用と変更

LED表示（`LEDDisplayView`）、楽曲解析の帯、ビジュアライザー、7セグメントの時刻表示、流れる文字表示、下部パネルの配色は、そのまま流用できます。
次の部品は、iPhone向けに変更か新規作成が必要です。

- 状態表示灯（`IndicatorColumnView`）は表示専用なので、押せるボタンとして並べる版を用意する。
- 音量の表示（`VolumeSlotView`）は縦向き専用で非公開の型なので、横向きにも描ける形に切り出す。
- 再生ボタン列（`TransportButtonsView`）は高さ34ptの区切り型なので、デッキ用に大きなボタン配置を新たに作る。
- 歌詞・情報パネル（`LyricsPanelView`）は2つの内容を切り替える構造なので、デッキのページとして個別に表示できるようにする。

## ライトモード

下部パネルの配色はライト（シルバー）とダーク（ガンメタル）の両方を持っているので、デッキとLEDドックの枠やボタンはこれに従います。
LED表示の色は外観モードと独立していて、設定の表示スタイルに従います。
既定の「ダーク」ではライトモードでも黒地に白文字のままで、「バックライト」を選ぶと黄緑のバックライトに黒文字になります。
ライブラリの画面はiOS標準のライト・ダークの配色を使います。

## 未決事項

- 横向き表示：案CのC-3（LED表示とVUメーターを並べたフルデッキ）を、デッキの横向き表示として採用するか。
- 出力先ボタン：AirPlayなどの出力先を選ぶボタン（`AVRoutePickerView`）は現在のアプリにない機能なので、追加するか。
- 書き出し：iOSでの書き出し方法（保存ダイアログか共有シートか）と、この課題で扱うか別の課題に分けるか。
- 「次に再生」ページ：再生中のリスト（一覧の絞り込み結果）を表示するだけにするか、並べ替えも可能にするか。

## 完了条件と確認方法

| 完了条件 | 確認方法 |
|---|---|
| 互換表示が解消している | iPhoneシミュレーターで上下に黒帯がなく、画面全体に表示されることをスクリーンショットで確認する |
| 操作部が画面内に収まる | 最小幅のiPhone（iPhone 17e相当）と最大幅（Pro Max）で、はみ出しや切れがないことを確認する |
| タップ領域が44pt以上ある | Accessibility Inspectorでドック・デッキ・調整シートのボタンの大きさを確認する |
| 機能の配置表のすべての操作に到達できる | 表の各行について、iPhoneで実際に操作できることを確認する |
| ライト・ダークとLEDの表示スタイルの組み合わせで表示が崩れない | 外観モード2種とLEDの表示スタイル2種の4通りで確認する |
| iPadとmacOSの画面が変わっていない | 両方をビルドし、主要な画面操作に絞ってUIテストを実行する |
| VoiceOverとUIの文言が日英で揃っている | 追加した文言を `Localizable.xcstrings` で確認し、日英それぞれのVoiceOverで読み上げを確認する |
